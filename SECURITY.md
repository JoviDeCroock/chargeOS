# Security policy

chargeOS is early-stage infrastructure that can affect access to an EV charger. Do not expose the development listeners directly to the internet or rely on it for production safety, billing, or electrical control.

Report vulnerabilities privately to the repository maintainers using the hosting platform's private vulnerability-reporting feature. Include the affected version/commit, impact, reproduction, and whether secrets or charging availability are at risk. Do not include real station credentials, raw RFID values, or personal charging records.

Until a formal support table is published, only the current default branch is maintained. The maintainers will acknowledge a credible report, coordinate a fix and disclosure, and avoid public detail that would put deployed owners at immediate risk.
