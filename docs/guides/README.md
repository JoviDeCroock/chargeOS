# chargeOS help

chargeOS lets you run charging software on infrastructure you control. Start with the task you want to complete. These guides are also available at **Help** in the app, including when the internet is unavailable.

- [Install the software](install.md): prepare a computer or server and open setup.
- [Deploy chargeOS](deploy.md): choose your server, create private credentials and start the software.
- [Use the owner console](owner-console.md): sign in, choose a charger, give temporary read access and export evidence.
- [Connect a charging station](connect-a-charger.md): prepare a reversible handover, record the Freedom Test and troubleshoot a connection.
- [Use your own AI key](ai-help.md): ask about configuration issues and optionally search manufacturer documentation.
- [Use several chargers or brands](brands.md): check an exact device and understand the current fleet limits.
- [Add a person](people.md): invite an employee or finance reviewer in the local employer workspace.
- [Send account emails](account-email.md): use your own mail provider for verification, recovery and invitation links in the local trial.
- [Add or remove an RFID card](rfid.md): manage a card and check whether the charger has accepted it.
- [Review home-charging reimbursements](reimbursements.md): follow a statement from imported sessions to finance approval.
- [Back up and recover](recovery.md): keep the information needed to move to another server.

If you are using chargeOS at work, your administrator can tell you which workspace you use. The **owner console** manages a physical charger. The separate **employer workspace** manages people and reimbursement records. An employer account does not grant control over a home charger.

Current release: the owner edge is for controlled lab and migration work. Employer accounts and reimbursements run locally; optional SMTP email delivery is available for that trial, while public account hosting and payment execution remain unfinished. A completed software deployment does not prove that a real charger works safely through an outage.

- [Share the company workspace](company-hosting.md): IT-managed HTTPS account pilot, approved work emails and current deployment/recovery limits.
